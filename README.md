# 🍽️ Restaurant React

A modern and fully responsive restaurant web application built with **React** and **Vite**.

This project provides an engaging food ordering experience with a clean and responsive interface, dynamic food browsing, shopping cart and wishlist functionality, user pages, and multiple dedicated sections.

## ✨ Features

- 📱 Fully responsive design
- 🍔 Dynamic food browsing
- 🛒 Shopping cart functionality
- ❤️ Wishlist functionality
- 🔎 Food item details
- 👤 User and registration pages
- 📖 About page
- 📩 Contact page
- 🧭 Client-side routing
- 🎨 Reusable React components
- ⚡ Fast development and production builds with Vite
- 📐 Responsive layouts for desktop, tablet, and mobile

## 🛠️ Tech Stack

- **React**
- **Vite**
- **React Router**
- **React Hook Form**
- **Yup**
- **Axios**
- **CSS3**
- **JavaScript (ES6+)**
- **Bootstrap Icons / Remix Icon**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Reza7Mohammadi/restaurant-react-vite.git
```

### 2. Navigate to the project

```bash
cd restaurant-react-vite
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## 🏗️ Production Build

To create an optimized production build:

```bash
npm run build
```

The production files will be generated inside the `dist/` directory.
